# Discord Games & Giveaways — النسخة الأساسية (المرحلة 1)

موقع عربي RTL لمسابقات القيف أوي على Next.js 15 + TypeScript + Tailwind + PostgreSQL.

## ما الذي تم تنفيذه في هذه المرحلة
- الصفحة الرئيسية: أقرب مسابقة جارية، قائمة المسابقات مع بحث وتصفية بالحالة، عداد تنازلي، عدد المشاركين، آخر الفائزين.
- صفحة المسابقة والمشاركة، وصفحة الفائزين مع بحث وتصفية.
- دخول الأعضاء عبر Discord OAuth2، وتسجيل يدوي بالاسم (يمكن إيقافه، ويُوضّح أنه لا يتحقق من الملكية).
- دخول الإدارة بجلسة موقّعة، وتجزئة bcrypt، وقفل مؤقت بعد 5 محاولات فاشلة، وفحص الصلاحيات على الخادم.
- لوحة الإدارة: إحصائيات، إنشاء المسابقات وتعديلها ونشرها وإلغاؤها، استبعاد مشاركين، السحب، الاعتماد والإعلان، المشرفون وصلاحياتهم، سجل العمليات، إعدادات الموقع.

## لم يُنفَّذ بعد (المرحلة 2)
التحديات والألعاب، المافيا، رفع أدلة الفوز، إشعارات Discord (Webhooks/Bot)، فلتر «نوع النشاط» (لا يوجد حاليًا إلا القيف أوي)، رفع الصور (الصورة حاليًا برابط).

## الإعداد
1. أنشئ قاعدة PostgreSQL في Neon أو Supabase وانسخ رابط الاتصال (يُفضَّل الرابط المجمَّع pooled).
2. `cp .env.example .env.local` واملأ القيم. ولّد السر: `openssl rand -base64 48`.
3. `npm install`
4. `npm run migrate` لإنشاء الجداول.
5. ضع `ADMIN_USERNAME` و`ADMIN_PASSWORD` (12 حرفًا على الأقل) ثم `npm run create-admin`، واحذف كلمة المرور من الملف بعدها.
6. `npm run dev` ثم افتح http://localhost:3000

### Discord OAuth2
في https://discord.com/developers/applications أنشئ تطبيقًا، وأضف Redirect:
`{SITE_URL}/api/auth/discord/callback` (محليًا: `http://localhost:3000/api/auth/discord/callback`)، ثم ضع Client ID وSecret في المتغيرات.

## النشر على Vercel
1. ارفع المشروع إلى GitHub واستورده في Vercel.
2. أضف المتغيرات نفسها في Settings → Environment Variables (واجعل `SITE_URL` رابط الموقع النهائي، وأضفه كـ Redirect في Discord).
3. نفّذ `npm run migrate` و`npm run create-admin` مرة واحدة من جهازك مع `DATABASE_URL` الإنتاجي.
4. انشر.

## الأمان
جلسات HttpOnly موقّعة (JWT) · الصلاحيات تُقرأ من القاعدة في كل طلب · السحب بمولّد تشفيري ومعاملة مقفلة · المشاركة داخل معاملة تمنع التكرار وتجاوز الحد · الوقت يُفحص بساعة قاعدة البيانات · كل عمليات الإدارة والسحب في `audit_log`.

## الاختبار
`npm test` يختبر منطق السحب والأدوات المساعدة.
